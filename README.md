# Vijay — Data Analyst Portfolio

A responsive static portfolio website for showcasing the ApexPlanet Data Analytics Internship work.

## Stack
- HTML5
- CSS3 (responsive layouts, dark navy + violet design system)
- Vanilla JavaScript
- GitHub Pages (deployment after local review)

## Run locally on Windows

### Option A — Open directly
Double-click `index.html` to open it in your browser. The site does not require a build step.

### Option B — Run a local server (recommended)
Open PowerShell in this folder and run:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

Press `Ctrl+C` in PowerShell to stop the server.

## Before publishing
1. Review the wording and ensure it accurately represents your work.
2. Confirm the dashboard image loads; it is currently referenced from the internship repository's public raw URL.
3. Replace the generic LinkedIn homepage link in `index.html` with your exact profile URL.
4. Check all external links and test mobile navigation.
5. Create a separate public GitHub repository named `Vijay-Data-Analyst-Portfolio`.
6. Push these files only after local review.
7. Enable GitHub Pages in repository Settings → Pages, using the `main` branch and `/ (root)` folder.

## Important notes
- No dataset values are fabricated for KPI cards. The hero's counts describe the four project phases, not measured business outcomes.
- The Task 2 chart is explicitly illustrative rather than a claim about actual monthly sales.
- The statistical summary reflects the Task 4 repository documentation. Interpret the non-significant result carefully; it does not prove equality between population means.
- The site links to the original internship repository rather than copying or modifying existing deliverables.
- This is a static website. It does not collect form submissions or store visitor data.
